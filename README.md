# 🪐 太陽系シミュレーター 3D

ブラウザだけで動く、本物の重力計算(N体シミュレーション)による太陽系の3Dシミュレーターです。スマホ・PC どちらでも動きます。

## できること

### 本物の重力モデル
- 太陽を含む全天体が互いに重力を及ぼし合う **N体シミュレーション**(リープフロッグ法+適応刻み幅)
- 単位系は AU・年・太陽質量(G = 4π²)。惑星の質量・軌道半径は実測値
- 天体の **重さ・位置を変えるとその瞬間から軌道が変わる**
  - 木星を1000倍重くすると他の惑星の軌道が乱れて弾き飛ばされたりする
  - 太陽に近づきすぎた惑星は **太陽に飲み込まれる**(太陽の質量が増える)
  - 太陽系から飛び出した惑星は通知が出る

### 操作できること
- 惑星を **ドラッグで好きな位置に移動** → そこから軌道がぐちゃぐちゃになる様子が見られる
- 天体ごとに **大きさ・重さ・太陽からの距離** をスライダーで変更
- **↺ リセット** ボタンでいつでも最初の状態に戻せる
- **🎯 追従** ボタンで好きな天体をカメラで追いかけられる
- 再生速度は 1日/秒 〜 5年/秒 で切り替え

### 本物のサイズ感
- 太陽と惑星の大きさの比率は **常に実寸どおり**(太陽の半径は地球の約109倍)
- 「表示サイズの倍率」を ×1 にすると距離も含めた実際のスケール感が体験できる(惑星はほぼ点!)
- 各天体には画面上で一定サイズのマーカーとラベルが付くので、小さくても見失わない

## 操作方法

| 操作 | PC | スマホ |
|---|---|---|
| 視点回転 | 左ドラッグ | 1本指スワイプ |
| ズーム | ホイール | ピンチ |
| 移動 | 右ドラッグ | 2本指スワイプ |
| 天体を選択 | クリック | タップ |
| 天体を動かす | 天体をドラッグ | 天体をドラッグ |

## ローカルで動かす

ビルド不要。リポジトリのフォルダで簡易サーバーを立てるだけです。

```bash
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

## 技術構成

- [Three.js](https://threejs.org/)(同梱、ビルド不要)
- 物理: リープフロッグ積分(KDK)+ 加速度に応じた適応サブステップ。接近遭遇時はソフトニングで発散を防止
- 依存パッケージ・ビルド工程なしの純粋な静的サイト
