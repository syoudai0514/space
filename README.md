# 🌌 銀河シミュレーター 3D

ブラウザだけで動く、宇宙の3Dシミュレーターです。スマホ・PC どちらでも動きます。

## できること

### 銀河系モード
- 天の川銀河を約7万個の星のパーティクルで3D表示
- 時間スライダーで **過去30億年前 〜 未来30億年後** の銀河の姿を見られる
  - 実際の銀河と同じ「フラット回転曲線」を採用しているので、時間を進めると渦状腕が巻き込まれ、過去に戻すとほどけていく
- ▶ 再生ボタンで時間をアニメーション再生(速度変更可)

### 太陽系モード
- 太陽と8つの惑星が公転する様子を3D表示
- 時間を変えると惑星の位置が変化(公転周期は実際の値)
- **地球と木星の入れ替え** ボタンで軌道を交換できる(周期はケプラーの法則で再計算)
- 惑星ごとに **大きさ・重さ** をスライダーで変更できる
  - 重くすると太陽との重力が強まり、公転が速くなる(ケプラー第3法則)
- 惑星をタップすると設定パネルが開く

## 操作方法

| 操作 | PC | スマホ |
|---|---|---|
| 視点回転 | 左ドラッグ | 1本指スワイプ |
| ズーム | ホイール | ピンチ |
| 移動 | 右ドラッグ | 2本指スワイプ |

## 携帯からアクセスする方法 (GitHub Pages)

1. このブランチを `main` にマージする
2. GitHub のリポジトリページで **Settings → Pages** を開く
3. Source を **Deploy from a branch**、Branch を **main / (root)** にして Save
4. 数分後に `https://syoudai0514.github.io/space/` で公開される → スマホのブラウザで開けます

## ローカルで動かす

ビルド不要。リポジトリのフォルダで簡易サーバーを立てるだけです。

```bash
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

## 技術構成

- [Three.js](https://threejs.org/) (CDN読み込み、ビルド不要)
- 銀河の星はGPUシェーダーで回転計算(スマホでも軽快)
- 依存パッケージ・ビルド工程なしの純粋な静的サイト
