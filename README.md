# 🪐 宇宙シミュレーター 3D

ブラウザだけで動く宇宙の3Dシミュレーターです。本物の重力計算(N体シミュレーション)による太陽系モードと、天の川銀河を眺める銀河系モードがあります。スマホ・PC どちらでも動きます。

## できること (太陽系モード)

### 本物の重力モデル
- 太陽を含む全天体が互いに重力を及ぼし合う **N体シミュレーション**(リープフロッグ法+適応刻み幅)
- 単位系は AU・年・太陽質量(G = 4π²)。惑星の質量・軌道半径は実測値
- 天体の **重さ・位置を変えるとその瞬間から軌道が変わる**
  - 木星を1000倍重くすると他の惑星の軌道が乱れて弾き飛ばされたりする
  - 太陽に近づきすぎた惑星は **太陽に飲み込まれる**(太陽の質量が増える)
  - 太陽系から飛び出した惑星は通知が出る

### 操作できること
- 惑星を **ドラッグで好きな位置に移動** → そこから軌道がぐちゃぐちゃになる様子が見られる
- 天体ごとに **大きさ・重さ・太陽からの距離** をスライダーで変更
- **⭕ この位置で円軌道に乗せる** ボタンで、乱れた惑星を安定軌道に戻せる → 好きな並び順の太陽系を設計できる
- **🔄 場所の入れ替え** で任意の2天体の位置・速度を交換できる(**太陽と惑星の入れ替えも可能** — 重力の中心が移動して太陽系が大改編される)
- **↺ リセット** ボタンでいつでも最初の状態に戻せる
- **🧹 軌跡を消す** ボタンを押すまで、軌跡は自動では消えない(容量が一杯になると古い部分を間引いて全履歴を保持)
- **🎯 追従** ボタンで好きな天体をカメラで追いかけられる
- 再生速度は 1日/秒 〜 5年/秒 で切り替え(軌跡は物理計算の細かいステップごとに記録されるので、高速再生でも滑らかな楕円になる)

### 本物のサイズ感
- 太陽と惑星の大きさの比率は **常に実寸どおり**(太陽の半径は地球の約109倍)
- 「表示サイズの倍率」を ×1 にすると距離も含めた実際のスケール感が体験できる(惑星はほぼ点!)
- 各天体には画面上で一定サイズのマーカーとラベルが付くので、小さくても見失わない

## 宇宙の歴史モード

- **ビッグバン(138億年前)から100億年後まで**を1本のスライダーで体験
- 膨張は実際の宇宙論(ΛCDMモデル: 物質+ダークエネルギー)のスケール因子を使用。未来は加速膨張する
- ビッグバンの閃光 → 火の玉宇宙 → **宇宙の晴れ上がり**(38万年)→ 暗黒時代 → 最初の星々 → 銀河の時代 → 現在 → 加速膨張の未来、と時代ごとに見た目が変化
- スライダーの前半は対数スケールになっていて、「最初の3分」のような一瞬の大事件もちゃんと見られる
- 各時代の解説テキスト付き(太陽系誕生、アンドロメダ銀河との衝突なども)

## 銀河系モード

- 天の川銀河を約7万個の星のパーティクルで3D表示
- 時間スライダーで **過去30億年前 〜 未来30億年後** の銀河の姿を見られる
  - 実際の銀河と同じ「フラット回転曲線」を採用しているので、時間を進めると渦状腕が巻き込まれ、過去に戻すとほどけていく
- ▶ 再生ボタンでアニメーション再生(速度変更可)

## 操作方法

| 操作 | PC | スマホ |
|---|---|---|
| 視点回転 | 左ドラッグ | 1本指スワイプ |
| ズーム | ホイール | ピンチ |
| 移動 | 右ドラッグ | 2本指スワイプ |
| 天体を選択 | クリック | タップ |
| 天体を動かす | 天体をドラッグ | 天体をドラッグ |

## ローカルで動かす

ビルド不要。リポジトリのフォルダで簡易サーバーを立てるだけです。

```bash
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

## 技術構成

- [Three.js](https://threejs.org/)(同梱、ビルド不要)
- 物理: リープフロッグ積分(KDK)+ 加速度に応じた適応サブステップ。接近遭遇時はソフトニングで発散を防止
- 依存パッケージ・ビルド工程なしの純粋な静的サイト
